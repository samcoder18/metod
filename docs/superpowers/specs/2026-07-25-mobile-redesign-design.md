# Мобильный редизайн лендинга «Метод Цуциева» — дизайн-документ

Дата: 2026-07-25
Статус: утверждён пользователем (брейншторм-сессия)
Охват: только `index.html` (главная). Блог не трогаем.

## 1. Цель и вводные

Полное переосмысление мобильной версии (< 1024px) одностраничного лендинга.
Десктопная версия (разметка, стили, JS) остаётся нетронутой.

Утверждённые решения пользователя:

- Глубина: полное переосмысление мобильной версии, не адаптация.
- Анимации: лёгкие reveal-анимации вместо GSAP-пинов и scrub.
- Hero: своя мобильная композиция под вертикальный экран.
- Навигация: полноэкранное меню (сейчас на мобильных меню нет).
- Плавающая кнопка «Записаться» внизу экрана.
- Изображения: перекадрирование существующих исходников, новых фотосессий нет.
- Подход: гибридный — мобильный CSS-слой + отдельная мобильная разметка hero.

Дизайн-диалы: `VARIANCE 7 / MOTION 3 / DENSITY 3`.
Бренд сохраняется: фон `#100F0D`, акцент `#C9A24B`, Tenor Sans (display),
Cormorant Garamond (serif), Onest (body). Новых цветов и шрифтов не вводим.

## 3. Архитектура

Брейкпоинт: всё мобильное < 1024px (`lg`). Десктопный код не меняется.

### 3.1 Новые файлы

- `assets/mobile.css` — все мобильные переопределения. Подключается в
  `index.html` после `tailwind.min.css`. Инлайн-`<style>` (233-582) не трогаем.
- `assets/mobile.js` — меню, sticky CTA, IO-reveals, свайп цитат. `defer`.
- `scripts/make-mobile-crops.mjs` — генерация кропов в `assets/m/*.webp`
  (ширина 828px, качество 80). Запуск вручную / из build.

### 3.2 Разметка

Принцип: дублируем только там, где композиция принципиально другая.

- Hero: отдельный мобильный блок `lg:hidden`; десктопный hero в `hidden lg:block`.
  H1: по одному на брейкпоинт (уточнено после code review Task 3): десктопный
  H1 нетронут в десктопном hero; мобильный заголовок — настоящий `<h1>` с
  sr-only SEO-префиксом. В DOM два `<h1>`, но на каждой ширине ровно один
  доступен AT и видим (второй `display:none`). Причина: `display:none`
  выносит десктопный H1 из accessibility tree на мобильных, а mobile-first
  indexing обесценивает скрытый H1.
- Остальные 11 секций адаптируются CSS из `mobile.css` (+ точечные
  `lg:hidden`/`hidden lg:block` в разметке).

### 3.3 JS-граница

В существующий инлайн-скрипт добавляется гейт `isMobile =
matchMedia('(max-width: 1023px)')` (точечные правки инициализации, не рефакторинг):

- Canvas «Сессии» — на мобильных не стартует; фон из `mobile.css`.
- Lenis, все ScrollTrigger (hero-параллакс, scrub манифеста, мобильная ветка
  сцен, параллакс фото) — не инициализируются.
- Десктопный `data-reveal` — гейтится; на мобильных работает `data-m-reveal`.
- Bottom-sheet'ы, FAQ, аккордеон полос, ротатор цитат — без изменений.

## 4. Композиции секций (мобильные)

### 4.1 Шапка + полноэкранное меню

Шапка 72px: логотип + бургер (2 линии, 44×44). Кнопка «Записаться» из шапки
убирается (дублирует sticky CTA), живёт в меню.
Оверлей меню: фон `background` + grain, пункты Tenor Sans
`clamp(2rem,8vw,3rem)`, stagger 60ms. Внизу: телефон, Telegram, CTA.
Закрытие: крест / Escape / клик по ссылке. Фокус-ловушка, блокировка скролла.

### 4.2 Sticky CTA

Появляется после hero (IntersectionObserver): `inset-x-4 bottom-4`, h-52px,
фон `accent`, текст `on-accent`, тень в тон, `safe-area-inset-bottom`.
Скрывается: на экране `#zapis`, при открытом меню/шторке.

### 4.3 Hero (мобильный)

Вертикальный постер: верх ~55% экрана — перекадрированный кадр 4:5 из
hero-видео (`<picture>`, webp 828px), `object-position` на руках, затемнение
снизу в фон страницы. Под ним: eyebrow «Индивидуальные сессии · Владикавказ»
(единственный eyebrow на странице), H1 «Метод Цуциева.»
`clamp(2.75rem,12vw,4rem)` в 2 строки, подзаголовок ≤ 20 слов, CTA на всю
ширину + телефон текстовой ссылкой.
Serif-цитата «Сначала тело…» переезжает под манифест (в hero она была бы
пятым текстовым элементом).
Видео `hero.mp4` на мобильных не загружается: `<source media="(min-width:1024px)">`,
preload постера — тоже с media.

### 4.4 Манифест

Без scrub-заливки: целиком видимый serif-текст, один fade-up.
Размер `clamp(1.6rem,5.5vw,2.2rem)`. Под ним — цитата из hero.

### 4.5 С чем приходят

Вместо горизонтальных полос — вертикальные карточки во всю ширину:
фото 4:5/3:4 сверху (пережатые `request-1..4`), под фото заголовок + 2 строки
текста на фоне `surface`, без наложения текста на фото. Чётные карточки
`ml-6`, нечётные `mr-6`.

### 4.6 Как проходит сессия

Без sticky-стека и canvas. Вертикальная timeline-лента из 4 сцен:
контурный номер (3.5rem, в потоке над заголовком, не absolute), заголовок,
описание; слева тонкая золотая вертикальная линия-соединитель.
Фон: статичный глубокий CSS-градиент в тон canvas-пресетам (по умолчанию).
Если визуально не хватит глубины — допускается один экспортированный
статичный кадр изолиний webp ≤ 60 КБ; решение фиксируется при реализации.

### 4.7 Техники

Список из 6 строк: `clamp(1.5rem,6vw,2rem)`, py-6, стрелка справа,
`:active` — золотая подсветка + сдвиг. Подсказка «Нажмите, чтобы узнать
подробнее». Bottom-sheet без изменений.

### 4.8 Обо мне

Фото мастера 4:5, bleed во всю ширину, рамка сохраняется. Под фото: имя,
абзац, строка стажа. 4 смысловых блока (~800 слов) — аккордеоном, открыт
первый.

### 4.9 Отзывы

Точки возвращаются (ранее были скрыты < 640px). Свайп влево/вправо
(pointer events, порог 40px, dy-гард). Стрелки на мобильных скрыты
(навигация — точки + свайп). Autoplay на мобильных отключён
(aria-live-спам и CLS от цитат разной длины). Стейдж — естественная
высота вместо absolute-стека (редакция после ревью: вместо JS-расчёта
min-height по самой длинной цитате цитаты переведены в поток
`display: none/block` по `.is-active`; ручное переключение = без CLS).
Цитата `clamp(1.4rem,5.8vw,1.9rem)`.

### 4.10 Цены

Строки → карточки на `surface`, радиус 12px: название + длительность в одну
строку, описание, цена `font-display` 1.75rem + «Подробнее» (существующий
sheet). Курс из 6 сессий выделен рамкой `accent/40`.

### 4.11 FAQ

Без структурных изменений. Вопросы до `1.35rem`, зона тапа ≥ 56px,
отступ рубрикатора под шапку 72px.

### 4.12 Запись

Ссылка сохраняет десктопный `clamp(3.5rem,15vw,17rem)` (на мобильных ≈ 56px —
достаточно крупно; редакция после ревью: отдельный мобильный clamp не нужен),
`:active` — заливка accent. Под ней телефон
и Telegram текстовыми ссылками.

### 4.13 Контакты

Адрес сверху, карта `aspect-[4/3]`, нижняя строка в колонку, зоны тапа ≥ 44px.

## 5. Анимации

Один механизм: `IntersectionObserver` в `mobile.js`, `data-m-reveal` → класс
`.is-in` (порог 0.2, `once: true`). Переходы только `transform`/`opacity`,
`cubic-bezier(0.16,1,0.3,1)`, 0.6s.

Варианты:
- `fade-up` (по умолчанию): `translateY(24px) → 0`.
- `fade`: только opacity (фото, фоны).
- `stagger`: `animation-delay: calc(var(--i) * 70ms)` — меню, карточки,
  техники, цены.

Анимируется: заголовки секций, карточки, сцены, цены.
Не анимируется: текст внутри карточек, FAQ-ответы, шапка.

`prefers-reduced-motion`: все reveal отключены одним медиа-запросом,
меню без stagger. Существующий reduced-motion блок десктопа сохраняется.

## 6. Производительность

- Мобильные кропы: webp, 828px, q80. LCP-кандидат (hero) — preload с
  `media="(max-width:1023.98px)"`.
- `hero.mp4` и его preload не грузятся на мобильных (media-атрибуты).
- `.grain`: на мобильных статичный (без анимации/repaint).
- Цели: LCP < 2.5s (3G), CLS < 0.1, ноль горизонтального скролла.

## 7. Обработка ошибок и краевые случаи

- Нет JS: меню недоступно (бургер — `<button>`), но весь контент читаем;
  sticky CTA и reveals не мешаем: reveal-скрытие гейтится классом `m-js`,
  который ставит сам `mobile.js` (редакция после финального ревью: ранее
  был гейт `html.anim` — заменён, чтобы при незагрузке `mobile.js`
  контент не остался скрытым).
- Нет webp: `<picture>` с jpg-фолбэком.
- Очень длинная цитата: стейдж в естественном потоке, обрезки нет (см. 4.9).
- iOS Safari: `100dvh`/`100svh`, safe-area-inset у sticky CTA и шторок.
- Старые Android без `backdrop-filter`: шапка получает непрозрачный фон.

## 9. Что не входит (YAGNI)

- Блог и его страницы.
- Изменение десктопной версии.
- Новые фото/генерация изображений.
- Изменение текстов (кроме переноса цитаты и подсказки в «Техниках»).
- Тёмная/светлая тема (сайт однотонный тёмный, остаётся таким).
