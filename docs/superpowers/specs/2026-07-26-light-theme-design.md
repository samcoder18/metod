# Светлая тема для десктопа — дизайн

Дата: 2026-07-26
Статус: утверждено пользователем (подход A + палитра «тёплая бумага»)

## Цель

Добавить на сайт переключатель тёмная/светлая тема. Переключатель и светлая
тема работают только на десктопе (viewport >= 1024px). Мобильная версия
всегда остаётся тёмной. Дизайн, контент и структура секций не меняются.

## Контекст проекта

- Статический сайт: `index.html`, `privacy.html`, `404.html`, `blog/index.html`
  и 4 статьи в `blog/`.
- Стили: Tailwind (v3-синтаксис конфига) скомпилирован в `assets/tailwind.min.css`;
  цвета зашиты hex'ами в `tailwind.config.js` под семантическими именами
  (`background`, `surface`, `raised`, `foreground`, `secondary`, `accent`,
  `accent-deep`, `border`, `on-accent`).
- Поверх Tailwind подключается `assets/mobile.css` (всё завёрнуто в
  `@media (max-width: 1023.98px)` — десктоп не затрагивается).
- `assets/blog.css` уже использует CSS-переменные `--color-*` — прецедент
  токенизации в проекте.
- В `index.html` ~30 инлайновых hex-значений (градиенты, SVG-заливки, один
  `style="..."`) и хардкод `rgba(16,15,13,0.88)` для прилипшей шапки.
- Сборка: `node scripts/build.mjs` копирует `assets/` в `dist/` как есть;
  `package.json` в корне нет, Tailwind пересобирается через
  `npx tailwindcss -i src/input.css -o assets/tailwind.min.css --minify`.

## Подход

CSS-переменные как единый источник правды (вариант A из обсуждения).
Отклонены: оверрайд-стили поверх скомпилированного Tailwind (хрупко,
война специфичности) и классическая схема `dark:`-вариантов (сотни правок
классов во всех HTML).

## Архитектура

### 1. Токены — `assets/theme.css` (новый файл)

Единственное место, где живут значения цветов. Подключается после
`tailwind.min.css` на всех страницах.

Тёмная тема (значения по умолчанию в `:root`, совпадают с текущими):

| Токен | Тёмная | Светлая |
|---|---|---|
| `--c-background` | `#100F0D` | `#F6F3EC` |
| `--c-surface` | `#171512` | `#FCFAF5` |
| `--c-raised` | `#1D1A16` | `#EDE8DD` |
| `--c-foreground` | `#ECE7DE` | `#1B1813` |
| `--c-secondary` | `#9C968C` | `#5C554A` |
| `--c-accent` | `#C9A24B` | `#8F7331` |
| `--c-accent-deep` | `#8F7331` | `#6E5926` |
| `--c-border` | `#27231E` | `#E2DCCF` |
| `--c-on-accent` | `#14120F` | `#FDFBF6` |

Светлая палитра — «тёплая бумага»: тёплый молочный фон, espresso-текст,
то же золото, затемнённое для контраста на светлом фоне (WCAG AA для
текста и кнопок).

Светлые значения задаются правилом:

```css
@media (min-width: 1024px) {
  [data-theme="light"] { /* светлые значения токенов */ }
}
```

Media query гарантирует «только десктоп» на уровне CSS: на мобильных
`data-theme="light"` игнорируется, тема остаётся тёмной без JS-проверок
ширины.

Значения хранятся в формате `R G B` (например `--c-background: 16 15 13;`),
чтобы работали opacity-модификаторы Tailwind (`bg-background/80`).

### 2. Tailwind — `tailwind.config.js`

Каждый цвет заменяется на ссылку на токен:

```js
background: 'rgb(var(--c-background) / <alpha-value>)',
// и т.д. для всех 9 цветов
```

Однократная пересборка `assets/tailwind.min.css`. Все существующие классы
в HTML продолжают работать без изменений.

### 3. Переключатель

- Кнопка в шапке справа, перед CTA. Класс `hidden lg:flex` — видна только
  на десктопе. На страницах блога — в их шапке (`#site-header`).
- Иконки sun/moon из библиотеки Phosphor, инлайн-SVG; переключение иконки
  в зависимости от текущей темы. Атрибуты: `aria-pressed`,
  `aria-label="Переключить тему"`.
- `assets/theme.js` (новый, подключается с `defer`): читает/пишет
  `localStorage["theme"]` (значения `dark`/`light`), ставит
  `document.documentElement.dataset.theme`, обновляет иконку и
  `aria-pressed`. Тема по умолчанию — тёмная (без записи в localStorage).
- В `<head>` каждой страницы — инлайн-сниппет (~3 строки), применяющий
  сохранённую тему до первой отрисовки (предотвращает вспышку тёмной темы
  при загрузке светлой):

```html
<script>try{var t=localStorage.getItem('theme');if(t)document.documentElement.dataset.theme=t;}catch(e){}</script>
```

- Плавность: `transition: background-color .4s ease, color .4s ease,
  border-color .4s ease` на `body` и ключевых поверхностях; отключается
  при `prefers-reduced-motion`.

### 4. Вычистка хардкода

- Инлайновые hex в `index.html` (~30 вхождений) заменяются на
  утилиты/токены.
- Добавляется десятый токен `--c-header-bg` (фон прилипшей шапки с
  прозрачностью, значение полное, не `R G B`): тёмная тема
  `rgba(16, 15, 13, 0.88)`, светлая — `rgba(246, 243, 236, 0.88)`.
- `assets/blog.css`: переменные `--color-*` перенаправляются на новые
  токены (`--color-background: rgb(var(--c-background))` и т.д.); хардкод
  `rgba(16,15,13,0.88)` в `#site-header.is-scrolled` заменяется на
  `var(--c-header-bg)`.
- Проверить стили форм и `assets/cookie-consent.js` на контраст в светлой
  теме (WCAG AA: 4.5:1 для текста, 3:1 для крупного).

### 5. Охват страниц

`index.html`, `privacy.html`, `404.html`, `blog/index.html`,
`blog/kak-ispravit-osanku/`, `blog/mify-o-massazhe/`,
`blog/pochemu-bolit-spina/`, `blog/stress-v-tele/`.

Каждая получает: `<link>` на `theme.css`, инлайн-сниппет в `<head>`,
кнопку-переключатель, `theme.js` с `defer`.

## Поток данных

1. Загрузка страницы: инлайн-сниппет читает `localStorage["theme"]` и
   ставит `data-theme` на `<html>` до отрисовки.
2. CSS: токены в `theme.css` дают значения под текущий `data-theme`;
   media query ограничивает светлую тему десктопом.
3. Клик по кнопке: `theme.js` переключает `data-theme`, сохраняет выбор,
   обновляет иконку.
4. На мобильных: кнопка скрыта, media query не пускает светлые значения —
   сайт всегда тёмный.

## Обработка ошибок и краевые случаи

- `localStorage` недоступен (приватный режим) — try/catch, сайт остаётся
  в тёмной теме, кнопка просто переключает `data-theme` без сохранения.
- Невалидное значение в `localStorage` — игнорируется, тёмная тема.
- FOUC — закрыт инлайн-сниппетом в `<head>`.
- `prefers-reduced-motion` — переходы цвета отключены.
- Hero-видео/постеры и логотип не меняются; проверяется, что они читаемы
  на светлом фоне.

## Тестирование

- Обе темы на всех 8 страницах (визуальный проход).
- Контраст акцента, кнопок, форм, cookie-баннера в светлой теме (WCAG AA).
- Отсутствие вспышки темы при перезагрузке с сохранённой светлой темой.
- Мобильный viewport (< 1024px): кнопки нет, тема тёмная при любом
  сохранённом значении.
- `node scripts/build.mjs --dev` собирает `dist/` без ошибок; `theme.css`
  и `theme.js` попадают в `dist/assets/`.

## Вне scope

- Автоматическая тема по `prefers-color-scheme`.
- Переключатель на мобильных.
- Любые изменения дизайна, контента или структуры секций.
